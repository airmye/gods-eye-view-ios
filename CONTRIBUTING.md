# Contributing

This is an early prototype, so small, focused pull requests are easiest to review.

1. Open an issue first for anything bigger than a bug fix.
2. Fork, branch, and keep changes small.
3. Build in Xcode and test on a device or simulator before opening a PR.
4. Never commit server URLs, API keys, or personal data.

Bug reports with iOS version, device, and steps to reproduce are very welcome.
